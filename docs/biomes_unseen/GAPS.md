# GAPS — Horizon API 0.2 (as proven by this repo) vs Biomes O' Plenty needs

Discovery basis: README.md, docs/CREATE_HMOD.md, docs/INSTALL_PC.md, docs/INSTALL_ANDROID.md, scripts/build_hmods.py, and all 6 example mods in src-mods/. Proven registry types ONLY: `horizon/block`, `horizon/item`, `horizon/creative_tab`, `horizon/mob_effect`, `horizon/entity_type`, `horizon/menu`, plus vanilla-style `recipe/`, `loot_table/`, `tags/`, assets (blockstates/models/textures/lang).

| Needed capability | Present? | Closest working alternative implemented |
|---|---|---|
| Biome registration | NO — no biome example/schema anywhere | 44 biome climate/color/weight definitions as std-only Rust data in `releases/biomes_unseen.hnmod` (`mixins/biomes_unseen/src/lib.rs`); all biome content blocks/items are in the .hmod so they are obtainable/placeable today |
| Worldgen (configured/placed features, trees, ore veins, surface rules) | NO | Ores/terrain blocks registered with loot/tags/recipes; natural generation awaits a worldgen registry |
| `.hnmod` manifest schema / horizon-mixins traits | NO — only "horizon-native.json + mixins/<id>/" is described, no example/schema | .hnmod ships a minimal descriptive horizon-native.json + std-only Rust (invents no engine API); compile via horizon-launcher is UNVERIFIED (no launcher/client in this repo, no rustc in sandbox) |
| Per-shape wood variants (stairs/slabs/fences/doors/boats/signs) | Not proven | Log/planks/leaves/sapling per wood set |
| Custom sounds / particles / fog-sky rendering hooks | NO | Vanilla sound groups via proven `properties.sounds`; colors carried in .hnmod data |
| Mod config files | NO capability listed | `Config` struct (toggles + weight_scale) in .hnmod Rust source |
| Client launch test | No Horizon client/launcher binary in repo | Verified by the repo's own spec validator (`build_hmods.py --check-only`) + `scripts/test_biomes_unseen.py`; in-client load is UNVERIFIED |

## Format decision (Phase 0)
- `.hmod` (API 0.2): loads on PC **and** Android 64-bit — this is the primary, fully verified deliverable: `releases/biomes_unseen.hmod`.
- `.hnmod`: PC-only, source-only, needs horizon-launcher compilation, cannot load on Android — delivered as `releases/biomes_unseen.hnmod` with the caveat above.
- Assets: Biomes O' Plenty assets were NOT copied (its assets are not under a permissive reuse license assumed here); all textures are original procedural 16x16 pixel art generated by `scripts/generate_biomes_unseen.py`. Names are kept for parity.
